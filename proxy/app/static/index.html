TCP 延迟代理 慢链路下“上传结束却收不到回执”复现工具

延迟自代理读到字节起算，连续数据流水发送（不按块累加等待）；每向应用缓冲 ≤ 64 KiB，满则暂停该向读取；单向 EOF 先冲刷待发字节再转发半关闭，反向继续到结束。双向都没有实际转发超过停滞时限的连接会被终止并标记 stalled（区分上行 / 等回执阶段）。
